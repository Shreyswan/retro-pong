# Retro Pong 🕹️

Ever think of the old days and the one thing that comes to mind is the good ol' games on the Atari 2600? 🤔
If only there was a way to relive those moments of playing Pong with your pal all day... 😌😌

Well look no further, cause this repo has just that!!

## Introducing Retro Pong !! 🎊🎊

This game of Pong, as simple as it sounds, a two player game of pong which keeps a track of your scores. 💪

But then whats so special about it??
Well I put the word Retro in it for a reason you know. The speciality of this game is that it has the aesthetic of a CRT TV which we used to play back in the day.

## How to use? 🤓

1. Make a new folder in your system.
2. Clone this repository using: `git clone https://github.com/Shreyswan/retro-pong.git`
3. Navigate to the pong folder
4. Run the HTML file by using a server like from VS code (Note double clicking the HTML works, but doesn't play the sounds.)

Enjoy your days with this simple yet nostalgic game of pong!!
